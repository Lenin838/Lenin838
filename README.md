### 🔔 Notification Router

**Fault-Tolerant Real-Time Notification System**

A production-oriented notification routing system designed around **priority queues, automatic provider failover and real-time monitoring**.

**Highlights**

* ⚡ Priority-based notification processing
* 🔄 Automatic provider failover
* 📬 SMS → Email fallback strategy
* 🌐 RESTful API
* 🔌 WebSocket / Socket.IO communication
* 📊 Live monitoring dashboard
* 🧱 Repository Pattern
* 💉 Dependency Injection
* 🏗️ Service-layer architecture
* 🗄️ MongoDB persistence
* 🔍 Delivery pipeline logging

**Architecture:** React → Express → Notification Service → Priority Queue → Providers → MongoDB → Socket.IO

[![View Project](https://img.shields.io/badge/View_Project-13B9FD?style=for-the-badge\&logo=github\&logoColor=white)](https://github.com/Lenin838/notification-router)
